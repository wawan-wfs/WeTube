WeTube Desktop by WFS Project — online runtime installer candidate

WeTube's application source retains the MIT notice of Stream Tube Desktop, copyright Avaneesh Inamdar. libmpv is separate software, not covered by that MIT notice. This installer retrieves the exact pinned archive directly from its original distributor (shinchiro/mpv-winbuild-cmake); no third-party DLL is embedded in the installer. Both archive and DLL SHA-256 are checked before installation.

Original distribution: https://github.com/shinchiro/mpv-winbuild-cmake/releases/tag/20261111
mpv source and license information: https://github.com/mpv-player/mpv
Build recipes and upstream component information: https://github.com/shinchiro/mpv-winbuild-cmake

A network connection, Windows x64, system tar.exe (Windows 10 1803+), and working system Vulkan loader if required by libmpv are prerequisites. If runtime verification or extraction fails, installation stops. No DLL is installed into System32. The installer candidate has not yet passed installation or playback tests.
