# Real Windows visual capture protocol
Use a dedicated, unlocked interactive Windows desktop with sufficient physical resolution. The installed candidate must support `--visual-probe`; the probe requires an absolute, empty, isolated `WETUBE_NATIVE_DATA_DIR`, never an existing user profile. It selects the actual production route, sets app UI scale, reports GPUI logical viewport and scale factor, and reports root/search focus. Playlist uses a local one-item fixture; other media routes use explicitly authorized fixture IDs/query via the application's normal provider path. No bypass or simulated provider data. Loading/error states may be captured, but are not a functional PASS.

Run `pwsh -STA -File native-src/tools/capture_visual_matrix.ps1 -Exe <candidate-exe> -OutDir <new-output-directory> -VideoId <authorized-id> -ShortId <authorized-short-id> -ChannelId <authorized-channel-id> -SearchQuery <authorized-query> -AuthorizedFixtures -Height 720`. The 160 combinations are 10 pages, four widths (720/856/1280/1920 logical px), four app UI scales (0.75/1/1.25/1.5). Optionally use `-RequiredDpi 96`, 120, 144 or another measured DPI on separately configured OS displays. The script checks exact visible foreground window/process, actual DPI, GPUI viewport, physical client dimensions and unclipped screen area. F6 trace records root → search → root. If dimensions or foreground do not match, mark NOT TESTED; do not crop or resize a screenshot to pass. Profiles and partial reports remain under the dedicated output directory for investigation. Never run on a desktop displaying confidential overlays or other applications.

Validate using `python native-src/tools/visual_evidence.py <output-directory> --require-all`. This checks PNG CRC/dimensions, hash, route, DPI/scale, duplicate cells and focus trace. It does NOT independently authenticate capture origin or certify visual quality. A separate human/native automation review must inspect content, clipping, contrast, focus traversal, controls, accessibility and playback. Capture is only CAPTURED; geometry export is not a screenshot. Required offline Windows workflow remains unchanged. Separate authorized online playback, yt-dlp, real GPU/Vulkan and full DPI acceptance remain mandatory for any full-parity claim.
