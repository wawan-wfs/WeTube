# Hybrid local-first CI — WeTube Desktop by WFS Project
Run `python native-src/tools/hybrid_ci.py --report local-evidence.json` from a checkout or use --source with the verified native ZIP. SQL probes use production SQL literals; FFmpeg validates a generated local motion/seek fixture. These are not Rust or Windows acceptance. Missing Rust is NOT TESTED; --require-rust returns 2 unless the portable Rust test passes.
The one-time provisioning workflow runs on a push that changes its own file, or manual dispatch. It exports an official rustup-pinned Linux x64 1.100.0 toolchain and a portable subset of registry dependencies. It checks each resolved package version and checksum against native Cargo.lock. No deployment, no profile data or credentials in artifacts. Retrieve both archives from this repository's trusted bootstrap run, independently check artifact integrity and use the emitted SHA256 values with import_local_bundle.py. The import rejects path traversal, links, special files and oversized bundles. After import pass --bundle PATH --require-rust to hybrid_ci.py. The portable tests use copied production modules and explicit GPUI-independent adapters, not the full app or Windows process controls. Only the Windows CI provides required native build/runtime/installer acceptance. Existing five mandatory jobs are unchanged. If bootstrap fails, do not substitute unverified binaries or declare a Rust PASS.
